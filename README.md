# Mini CRM

A modern and responsive Client Lead Management System built to help businesses efficiently manage and organize customer leads.

The application provides a clean and interactive dashboard for handling client information, tracking lead progress, and managing follow-ups in an organized way.

The system allows admins to monitor lead status updates such as new, contacted, and converted, making it easier to manage the complete client workflow. 

It also helps businesses keep track of communication and improve lead management efficiency through structured data handling.

Designed with a user-friendly interface and responsive layout, the application delivers a smooth experience across desktop, tablet, and mobile devices. 

The dashboard focuses on simplicity, accessibility, and performance to ensure easy navigation and effective management.

This project demonstrates real-world full stack development concepts including CRUD operations, authentication, REST API integration, frontend and backend connectivity, and database management.

It reflects my understanding of building scalable, business-oriented web applications with a focus on functionality, responsiveness, and user experience.
